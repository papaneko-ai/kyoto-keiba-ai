```bash
python -m diagnostics.p1_operator_original_handoff --bundle authorized_originals.zip --snapshot frozen_snapshot.json --observed-utc 2026-11-14T03:00:00+00:00 --channel PC --out operator_handoff.json
```

※日付はコマンドの書式例であり、実取得日時や実証済み原本を表さない。出力先の既存ファイルや入力原本の上書きを拒否。改ざん価格・最終オッズ・名簿不一致では成功レシートを作らない。
