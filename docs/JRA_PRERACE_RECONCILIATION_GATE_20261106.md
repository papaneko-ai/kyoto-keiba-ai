# 発走前出馬表とJRA確定結果の独立照合ゲート（2026-11-06）

## 目的
既存のJRA実HTML取得・154頭の結果行抽出を再実施せず、未実装の発走前出馬表と正式な競走馬IDの照合に必要な安全ゲートを分離実装する。

## 原本の確認結果
GitHub Actions Artifact 13393704408 の公式結果HTML（2026-10-31京都12R分）は結果154行・プロフィール遷移トークン154件を含む。公式出馬表として保存された entries.html は「出馬表 開催選択　JRA」という開催選択画面で、レース別の発走前出馬表ではない。すなわち実レースでの「発走前全頭照合合格」は依然として **未達成**。

## 実装した独立ゲート
`diagnostics/jra_pre_race_audit.py` は取得時刻が予測締切より前、JRA公式HTTPSの保存元、原本ハッシュとバイト一致の検証済み宣言、出馬表の構造確認、馬番/枠番/馬名、出走/取消/除外区分、正式な馬IDの根拠、結果との一致を検査する。欠測・不一致なら BLOCKED。予測に事後結果を使用できないよう ready_for_prediction は常に false。完全な根拠は後続の取得・検証器が提出しなければならない。

## 誤認防止
テスト中の正式ID値やレースIDは架空の合成フィクスチャであり、JRA実データから正式馬IDが抽出できたという意味ではない。`raw_sha256_verified=True` は原本バイトとSHA-256を照合した独立インジェスタのみが設定してよい。このモジュール単独では自己申告の真偽は証明できない。取得タイミング、利用条件、取消情報の公開時刻、同着/失格、結果の訂正は追加検証が必要。GitHub CI合格も別途確認する。
