## 減少・変更の扱い
- 認定率が減少するなら原因を `IMPLEMENTATION_REGRESSION` / `PREVIOUS_ACCEPTANCE_ERROR` / `SCOPE_CHANGE_WITH_NEW_VERSION` に分類して証拠を残し、静かに数値を修正しない。
- 分母・採点の定義変更は新しいバージョンの指標として保存し、旧数値との増減比較を禁止する。
- 研究用CI成功によって実開催6・実用100へ加点しない。コードが存在するだけではAにしない。
- GitHub参照できないときは最新値を推定しない。前回確定値として明示して停止。
- 「大きな節目」は事前に宣言した受入条件を満たし、前回から新たな認定件数が増加するか、新しい固定母数における未反映Cが減少した証拠を保全した場合に限る。単なる文書保存・同じテストの再実行を達成率増加としない。
