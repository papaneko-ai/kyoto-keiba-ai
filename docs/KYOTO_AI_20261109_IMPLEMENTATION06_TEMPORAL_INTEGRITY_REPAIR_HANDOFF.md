# 京都競馬AI｜実装06・P1未来時点混入防止の局所修正｜2026-11-09

## 目的と原因
前回追加した未発走開催の原本検査では、各原本の `captured_utc < cutoff_utc` のみを調べていた。そのため、当該開催日と矛盾する締切日、および検査時点よりも未来の取得時刻であっても、内部的な整合だけなら通過し得た。これは発走前証拠の誤認につながる。

## 変更したファイル
- `diagnostics/jra_p1_future_evidence.py` の `verify(..., observed_utc=None)` に検査観測UTCを導入。入力がない場合のみ実行時UTCを使用。原本に記載された取得UTCが観測UTCより未来なら `future_dated_source` で拒否。
- `cutoff_utc` を日本標準時へ換算した日付が、manifestの `meeting_date` と一致しなければ `cutoff_not_on_meeting_day_jst` で拒否。JRA正式発走時刻を判定するものではなく、日付の矛盾だけを検出する。
- `tests/test_jra_p1_future_evidence.py`: 従前8件の固定時刻入力を整備し、未来日時・誤った開催日・UTC/JST境界・観測時刻一致・非UTC観測入力の5件を追加。合計13件をCI対象とする。
