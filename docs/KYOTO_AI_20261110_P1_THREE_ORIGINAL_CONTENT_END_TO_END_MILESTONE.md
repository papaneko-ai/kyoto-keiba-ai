# 京都競馬AI・広域節目：P1保存済み3原本の実内容一括照合（2026-11-10）

## 節目の定義と到達
対象は保存済みレース出馬表HTML、馬連オッズHTML、枠連オッズHTMLの独立した3原本と、構造化snapshotの内容照合。SHA256・取得時刻・レース/日付・発走前締切・市場組合せ完全性の従来ゲートを維持しつつ、既存のPC/SP出走馬解析器と既存の馬連/枠連オッズ行列解析器を統合した。**新規解析器は作らず既存成果を再利用。**

厳密モードは racecard_channel=PC/SP、verify_market_originals=True。原本の馬番・枠番・馬名、馬連の組合せと価格、枠連の実際に成立する組合せと価格を構造化snapshotと照合。SHA一致のみで価格一致と見なさない。改ざんされた価格、馬名、欠損市場表、最終オッズ、偽チャンネル、原本不一致、締切後の取得を拒否。枠連HTML表には成立しない同枠組合せも含まれ得るため、既存監査器が算出したACTIVEな異なる2頭から成立する組合せのみを比較。すべて研究用・オフラインであり、予測/購入は不許可。

## 再現可能な入口
diagnostics/p1_three_original_content_cli.py を追加。ローカルに保存した既存bundleとsnapshotを用い、以下を実行する。

    python -m diagnostics.p1_three_original_content_cli --bundle evidence.zip --snapshot snapshot.json --observed-utc 2026-11-13T05:00:00Z --channel PC --out strict_receipt.json

成功時は内容一致の証跡を排他的に新規保存。既存レポートの上書きは禁止。失敗時は成功証跡を作らない。SP原本なら --channel SP。ネットワーク・DB・予測アプリへの接続なし。
