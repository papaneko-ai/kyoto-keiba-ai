# 京都競馬AI — 追加確定開発条件：大量データの活用と勝利条件発見
策定日：2026-11-05
状態：ユーザー承認済みの開発方針。**実装完了や効果実証を意味しない**。
適用対象：京都競馬AI v14以降、馬連・枠連予測、自動仮想投資、自己改善機構。
本記録は既存の開発方針v3に対する**追加条件**。旧方針を置換・削除しない。

## 1. 必須の開発目的
大量の過去および今後蓄積するJRA実レースデータから、勝ち馬・連対馬に共通する**予測可能な条件や交互作用**を探索する。
発見した条件は必ず既存予測器への特徴量候補とし、**未知の時系列データで確率推定・馬連枠連の的中率・回収率などへの寄与を実証してから採用**する。
蓄積量の増加や過去データ内の好成績は、それだけではモデルの進化とは判定しない。

## 2. データの基礎スキーマ
- race: 開催日・場所・R番号・コース・距離・馬場・天候・レース条件・発走日時
- runner: 正規の競走馬ID・馬番・枠番・年齢・性別・騎手・調教師・斤量・出走取消など
- prior_form: 過去走の条件・着順・走破タイム・上がり・通過順位・頭数・体重等
- snapshots: 発走前に確認できた出馬表、馬体重、馬場状態、オッズ、**取得時刻と一次資料**
- outcomes: 確定着順・払戻・確定日時（予測時点の特徴量に混入させない）
- version: モデル・特徴量・データセット・抽出ロジックのバージョンとSHA-256
- prediction: 使用できた時点情報、対象レース・予測確率、推奨買い目・投資額を発走前に固定保存

## 3. 勝利条件発見エンジン
- コース×距離×馬場×脚質、距離変更、前走と相手レベル、騎手・調教師・枠の交互作用等を探索する
- 単純な勝者特徴の頻度だけでなく、同レースの非勝者および出走母数を比較する
- 勝率・連対率だけでなく、レース内の相対能力、馬連・枠連の**組合せ確率**への有用性を評価する
- 条件発見方法（集計、正則化回帰、木モデル等）は固定的に限定せず、複雑さと計算費用を考慮する
- 各条件に標本数、支持レース数、信頼区間等、期間・条件差・複数仮説探索の検証結果を付ける
- 偶然の相関、事後情報リーク、人気・オッズへの過度な依存を検出する
- 統計上の発見と因果関係を混同しない

## 4. 理論との統合
- 既存v14を基準モデルとして保持する
- Bolton–Chapman型やその他の能力モデル、Benter型能力＋市場情報統合、Harville/Plackett–Luceによる組合せ確率、必要ならオッズバイアス調整・保守的資金配分を**比較候補**にする
- 発見された条件を特徴量として加えたモデルと、追加しないモデルを同一条件で評価する
- 未検証の「東京大学教授の理論」を確認済みの理論名と取り違えない

## 5. 学習・審査・採用・採用後監視
1. 過去の発走時点で入手できた情報のみを特徴量化（ラベルは事後確定結果）
2. 時系列順の学習・選定・完全保留テストに分け、ウォークフォワード検証を実施
3. 既存モデルと新モデルの**同じ対象レース・買い目数・投資上限**での成績を比較
4. 的中率（分母と「1点以上的中」の定義を統一）、馬連・枠連別的中率、回収率、累積損益、最大ドローダウン、確率較正（Brier/log loss）を記録
5. 改善幅を**百分率とパーセンテージポイント**で表示し、標本数・不確実性も報告
6. リリース前に改良効果が確認できなければ採用保留／不採用
7. 新旧両モデルで次の開催日の**事前登録型**ペーパートレードを並走し、継続監視
8. 悪化が十分な証拠で確認されたら新モデルを停止、過去の正常モデルに復帰できること。未確定・標本不足なら判定保留
9. 別の特徴量・学習条件・理論を独立の改善候補として試し、失敗案と検証結果も保存する

## 6. 技術・運用上の保護
- 公開中の main/app.py とTurso本番データは、独立ブランチの検証が完了するまで変更しない
- 取得データが欠落・不鮮明な場合は架空値で補わず予測を保留する
- 結果や最終オッズを事前オッズとして扱わない
- GitHub Actions等で適切な頻度・上限・公式条件を守ってデータ取得し、追加有料サービス/API課金は原則使わない
- 現在の診断ブランチは jra-html-diagnostic-20261105。最新のGitHub状態を再取得してから変更する
- 機能の完成表示には、実データによる再現テスト・精度検証・比較ログを必須とする

## 7. 実装の順序
1. 出馬表→全出走馬ID→過去走の自動取得を検証し、予測可能時点のスナップショットを保存
2. 特徴量・勝利条件発見の再現可能な分析器を**公開アプリと独立**して実装
3. 時系列バックテストと同条件のモデル比較・条件採否判定を実装
4. 事前登録型の仮想投資、確定結果の自動採点、成績ダッシュボードを実装
5. 新モデル採用後の旧モデル並走、悪化警告・復帰・代替案探索を実装
6. 実データで効果を示せた範囲だけを公開アプリへ安全に統合
