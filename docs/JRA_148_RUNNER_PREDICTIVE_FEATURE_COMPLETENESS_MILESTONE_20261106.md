## 2. 実HTMLの構造の違いを根本から処理
- `jra.jp` はJRA公式の実在ホスト。既存プロフィール解析器が `www.jra.go.jp` 等のみを許可し不当に停止したため、公式 `jra.jp` も検査対象に加えた
- JRA公式プロフィールの出走履歴表を持たない新馬は、本人識別が一致し、公式画面の出走履歴見出し・出馬表の日付0件など根拠のある場合のみ、明示的に `NO_HISTORY_TABLE_WITH_IDENTITY_PROOF` として認める
- JRA公式で過去走の着順が `除外` の場合は `nonfinish_rows` に分離し、着順・勝率・順位百分位から除外
- 2026-11-07京都8Rの障害出走馬の過去成績には、実際のJRA公式で `芝ダ3110`、`芝ダ3200`、`芝ダ2970` のコース表記があった。これを通常芝・通常ダートに丸めず、`芝ダ` という区別された種別として保持
- 原本はGitHub Actions ArtifactからダウンロードしてSHA-256を照合し、**同じ原本を再解析**した。HTMLを再度JRAから取得して再試験することは避けた
- 途中の正規表現更新時に生じた関数重複による構文エラーは、GitHub CIログで検出し、重複を削除。修正後は全12プロフィールの再解析・既存のオフライン回帰テストが合格
